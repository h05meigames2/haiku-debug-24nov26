A Python 3 program (standard library only, no network) that writes one original haiku about debugging to `entry.txt` in the output directory. The haiku is a constant in the source, so every run writes exactly the same bytes — and the program validates the haiku itself first: exactly 3 lines, syllable counts 5-7-5, at most 200 characters.

> Cursor blinks at three
> a lone log line confesses
> and the bug was me

## Run it

```sh
python3 main.py
```
